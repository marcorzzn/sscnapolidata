# Convenzioni

- **Date**: Formato ISO YYYY-MM-DD.
- **Stagioni**: Formato YYYY-YYYY (es. 1986-1987) per allinearsi all'uso standard nel sito e Wikipedia.
- **Nomi colonne**: Utilizzare l'italiano ove possibile per coerenza (data_raccolta, valore_nuovo). Fanno eccezione ID e timestamp se usati comunemente in inglese (es. batch_id, timestamp_utc).
- **Stati di Copertura (stato)**:
  - completo: Dati presenti e verificati.
  - parziale: Dati parziali.
  - nd: Dato non disponibile (la fonte non lo riporta).
  - na: Dato non applicabile (es. marcatori per uno 0-0).
- **Livelli di Confidence**: alta, media, bassa.
- **Verifica**: da_verificare, verificato.
- **Stati d'uso risorse (stato_uso)**: da_usare, usato, da_verificare, scartato.
- **Tipi risorsa (tipo)**: wikipedia, articolo, foto, report_lega, database, libro, video, documento_ufficiale, altro.
- **Licenze risorsa (licenza)**: `CC BY-SA 4.0`, copyright, pubblico dominio, sconosciuta.
